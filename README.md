# Campus Counsel

> Maharashtra's trusted engineering admission and career guidance platform — MHT-CET, JEE, CAP Rounds, college selection & career planning.

## About

Campus Counsel helps 12th-pass students across Maharashtra navigate the engineering admission process with personalized mentorship from verified industry mentors and experienced faculty.

We cover:
- MHT-CET & JEE counselling
- CAP Round strategy and option form filling
- College & branch selection
- Cutoff and seat-matrix analysis
- Career planning and scholarship guidance

## Tech Stack

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Framer Motion animations
- Deployed on Netlify

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The `dist/` folder is ready for Netlify deployment (`netlify.toml` included).
